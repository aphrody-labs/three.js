GutterFillGenerator

Fills the gutters of a baked map: the texels outside the charts of a UV atlas, e.g. of a light map or an ambient occlusion map. Texture filtering reads texels on both sides of the border of a chart, and the mip levels of a map average whole blocks of texels, so empty gutters show up as dark outlines around the charts, the more the farther away the map is seen. This fills every texel outside the charts with the values of the nearest charts.

The coverage of the map is read from its alpha: texels with an alpha above zero are covered, e.g. in a light map of LightMapper or a map stitched by SeamStitchGenerator. The fill is a push-pull in one chain of levels: the map is halved down to one texel, averaging the covered texels, then, from the coarsest level to the finest, the uncovered texels of each level are filled from the level below, upsampled with filtering. The covered texels keep their values, the filled texels have an alpha of zero.

Like PMREMGenerator, the generator can fill many maps, and the caller owns the results.

This class can only be used with WebGPURenderer and a WebGPU backend.

Code Example

const gutterFill = new GutterFillGenerator( renderer );
const renderTarget = new THREE.RenderTarget( size, size, { type: THREE.HalfFloatType, generateMipmaps: true, minFilter: THREE.LinearMipmapLinearFilter } );
gutterFill.generate( lightMapper.texture, renderTarget );
material.lightMap = renderTarget.texture;

Import

GutterFillGenerator is an addon, and must be imported explicitly, see Installation#Addons.

import { GutterFillGenerator } from 'three/addons/utils/GutterFillGenerator.js';

Methods

.dispose()

Frees all internal resources.

.generate( source : Texture, renderTarget : RenderTarget ) : RenderTarget

Fills the gutters of a map.

source

The map, with an alpha above zero at its covered texels.
renderTarget

The render target of the filled map, resized to the map. The map must not be its texture. By default, a new half float render target.

Default is null.
Returns: The render target of the filled map, with the UV channel of the map.
