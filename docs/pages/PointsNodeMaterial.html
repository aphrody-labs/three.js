PointsNodeMaterial

Node material version of PointsMaterial.

This material can be used in two ways:

  • By rendering point primitives with Points. Since WebGPU only supports point primitives with a pixel size of 1, it's not possible to define a size.
const pointCloud = new THREE.Points( geometry, new THREE.PointsNodeMaterial() );
  • By rendering instanced quads with Sprite. In this case, size is honored, see PointsNodeMaterial#sizeNode. Set Sprite#count to the number of points.
const instancedPoints = new THREE.Sprite( new THREE.PointsNodeMaterial( { positionNode: instancedBufferAttribute( positionAttribute ) } ) );
instancedPoints.count = positionAttribute.count;

Constructor

new PointsNodeMaterial( parameters : Object )

Constructs a new points node material.

parameters

The configuration parameter.

Properties

.alphaToCoverage : boolean

Whether alpha to coverage should be used or not.

Default is false.

Overrides: SpriteNodeMaterial#alphaToCoverage

.isPointsNodeMaterial : boolean (readonly)

This flag can be used for type testing.

Default is true.

.sizeNode : Node.<vec2>

This node property allows to overwrite the point size defined by size. The size is in pixels, additionally scaled by distance when sizeAttenuation is true.

Note that WebGPURenderer always renders point primitives with a size of 1 pixel (with both backends). Consequently, this node has no effect when the material is used with Points. If an application wants to render points with a size larger than 1 pixel, the material should be used with Sprite and instancing.

Default is null.
