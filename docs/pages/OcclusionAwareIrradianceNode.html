OcclusionAwareIrradianceNode

A generic class that can be used by nodes which contribute irradiance that already accounts for ambient occlusion, e.g. global illumination. Unlike IrradianceNode, the contribution is not modulated by the ambient occlusion of the lighting model. Used in NodeMaterial.

Constructor

new OcclusionAwareIrradianceNode( node : Node.<vec3> )

Constructs a new occlusion-aware irradiance node.

node

A node contributing irradiance that accounts for ambient occlusion.
